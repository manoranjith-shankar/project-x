John

Private workspace agent. Turns mail, calls, calendar, and pipeline into one action—and holds it until you approve.

1 · The problem

The company already decided. The mail about to leave says something else.

Pieces sit in different places: minutes from the call, overnight mail, an unsent draft, today's calendar, the deal sheet. Teams still ship whichever reply is fastest. That reply becomes the record.

Agreed on the call Payroll stays closed.
CFO is mailed only after Priya says yes.
Unsent draft + client mail Open the payroll mailbox.
Mail the CFO every Friday on its own.

2 · Why?

Why this problem, and why an agent

  • Cost is real. Wrong confirmation is written permission—payroll access, an unchecked CFO number, and a security review that files your mail.
  • One morning, one product. Brief, follow-up, quiet deals, and "what did we approve?" are the same desk, not four tools.
  • Rules and search are not enough. Nothing in one file flags the contradiction; something must read sources together and draft the fix.
  • John's job. Draft waits. Approve writes the action log. The next question must quote that log—it cannot invent an earlier yes.
  • Scoped workspace. Only sources you added open here. Out-of-scope asks stop before a draft is written.

3 · Architecture

Ask → classify → skill → tools → worker → draft → log

Flash classifies (brief, follow-up, quiet deals, recall, or refused). Pro worker reads only allowlisted sources and proposes drafts. UI shows skill name, tool trace, and approve/hold—not a black box.
