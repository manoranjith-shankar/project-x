# John AI Agent

The judge-facing workflow-agent prototype lives in [`prototype/`](./prototype/).

## Run locally

```bash
cd prototype
npm install
cp .env.example .env
# Add OPENROUTER_API_KEY to .env
npm start
```

Hermes Agent must also be installed. Follow the complete setup, verification, troubleshooting, and architecture notes in [`prototype/README.md`](./prototype/README.md).

- Local application: `http://localhost:4740`
